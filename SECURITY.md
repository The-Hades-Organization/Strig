# Security policy

**English** · [Português (Brasil)](#política-de-segurança)

Themis decides who can access what, so a bug that grants access it should not is a security issue.

## Reporting a vulnerability

Report it privately through GitHub: **Security → Report a vulnerability** on this repository ([direct link](https://github.com/The-Hades-Organization/Themis/security/advisories/new)). Please do not open a public issue.

Include the spec, the grants and the request that reproduce the problem, the decision you got and the one you expected. We aim to acknowledge reports within 7 days and will keep you informed until a fix is released.

## Supported versions

Themis is pre-1.0. Only the latest commit on `main` receives security fixes.

# Política de segurança

A Themis decide quem acessa o quê, então um bug que libera acesso indevido é um problema de segurança.

Reporte de forma privada pelo GitHub: **Security → Report a vulnerability** neste repositório ([link direto](https://github.com/The-Hades-Organization/Themis/security/advisories/new)). Não abra issue pública. Inclua a spec, os grants e o pedido que reproduzem o problema, a decisão que saiu e a esperada. A meta é confirmar o recebimento em até 7 dias.

Antes da 1.0, só o último commit da `main` recebe correções de segurança.
